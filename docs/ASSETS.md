# Asset provenance

- Interface, CSS, graph layout and Relay wordmark are original for this repository.
- Icons come from the installed `lucide-react` package, distributed under the ISC license; see [Lucide license](https://lucide.dev/license). No icons are loaded from a remote CDN.
- Typography uses the browser's system sans-serif and monospace fonts; there are no external font requests or bundled font binaries.
- Example names, amounts, workflows and destinations are synthetic. No private application source, customer data, credentials or analytics are included.
- `docs/screenshots/desktop.png` and `mobile.png` are actual Playwright captures of the running application with synthetic populated execution state, generated by `tests/e2e/relay.spec.ts`. They are not rendered mockups.
- Source code is MIT licensed. Dependency licenses remain with their respective packages.
